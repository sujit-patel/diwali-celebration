# Happy Diwali 2026 🪔 | शुभ दीपावली

A stunning, premium-quality, fully responsive, single-page Diwali celebration website built with **HTML5, CSS3, and Vanilla JavaScript**.

Experience the divine festival of lights through realistic animated diyas, customizable greetings, sky-illuminating fireworks, and seamless sharing across WhatsApp, Facebook, and mobile devices.

![Happy Diwali](assets/favicon.svg)

---

## ✨ Features

- **🪔 Sacred Interactive Diya:**
  - Multi-layered realistic CSS flame animation with organic flickering and ambient lighting.
  - Interactive touch/click that kindles the flame, triggers expanding shockwave ripples, and spawns rising golden sparks.
  - Inspirational blessings that cycle with each light kindle.
  - *"Ignite Grand Deepotsav"* button that illuminates a garland of lamps and launches celebratory fireworks.
- **💌 Personalized Diwali Wishes Generator:**
  - Enter your name and optional recipient name.
  - Choose from 4 curated greeting styles:
    1. *Traditional Blessings* (Spiritual prosperity and divine grace)
    2. *Family & Love* (Warmth, togetherness, and sweet memories)
    3. *Friends Special* (Sparklers, sweets, and celebration)
    4. *Success & Prosperity* (Career growth and boundless abundance)
  - Optional custom note input with live character counter.
  - Renders a festive greeting card with golden filigree corners, watermark rangoli, and auspicious seals.
- **📲 Instant Multi-Channel Sharing:**
  - **WhatsApp Share:** Pre-formats the greeting with recipient and sender names, plus a shareable link.
  - **Facebook Share:** Instant social share dialog.
  - **Copy Greeting:** Copies formatted festive message directly to clipboard with animated toast notification.
  - **Native Web Share API:** Seamless device share sheet on mobile.
  - **Personalized URL Parameters:** Links preserve `?to=...&from=...&style=...` so recipients open their own personalized greeting card automatically!
- **🎆 Canvas Fireworks & Floating Embers:**
  - High-performance HTML5 Canvas fireworks physics engine.
  - Automatic celebration bursts and interactive click-to-burst anywhere on screen.
  - Respects `prefers-reduced-motion` and pauses when tab is hidden.
- **🔔 Web Audio API Synthesizer (100% Offline):**
  - Resonant brass temple bell chime when kindling the diya.
  - Soft celebratory firework pops and card creation fanfare.
  - Zero external MP3 files or network requests required.

## 🚀 Getting Started

Simply open `index.html` in any web browser:

```bash
# Direct launch in your default browser
# Windows:
start index.html

# macOS:
open index.html

# Linux:
xdg-open index.html
```

Or serve via any static HTTP server:

```bash
npx serve .
# or
python -m http.server 8000
```
